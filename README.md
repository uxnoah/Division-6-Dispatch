# The Division 6 Dispatch

Weekly paper for Division 6 of the JLFB Bowl 9 Cat H2H 3RR 3.0 fantasy basketball league.

Each Monday: open the `papers` folder, choose "Add file", then "Upload files",
and drop in the HTML file saved from the Press Room. The home page lists every
file in `papers/` with "week-" and a number in its name.
